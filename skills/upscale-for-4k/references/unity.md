# Unity 资源接入

在修改 Unity 图片、导入配置或消费节点前读取。项目规则与当前实现优先，下面是核验项，不是要求迁移整个管线。

## 像素与显示尺寸

- 读取 `ProjectSettings/ProjectVersion.txt`、相关导入器及 Canvas/相机配置。屏幕分辨率翻倍不保证 UI 倍率翻倍；存在 Canvas 缩放上限、父节点缩放、安全区和相机适配时，以运行测量为准。
- `sourcePixels > runtimePixels` 常意味着导入或图集降采样；检查平台覆盖、Max Size、图集变体与缩放。压缩质量和像素尺寸是不同问题。
- `Image` 的固定 RectTransform 布局通常不需要随原图升级而扩大。检查 `SetNativeSize`、布局组和运行时赋图，确认没有以原图像素重设布局。
- `SpriteRenderer` 的世界尺寸受像素尺寸与 PPU 共同影响。放大源图而保持世界尺寸时，按相同比例调整 PPU。Sliced/Tiled 的边框、PPU 和角块比例需要一起核验，不照搬普通 Image 的处理。
- 自定义网格、DOTS、粒子、UV 切片或 Multiple Sprite 可能直接依赖源图像素。先查尺寸及 UV 的生成方式，不能只放大 PNG。

## 引用与导入

- 修改前按 GUID 和资源路径查引用，包括作者场景、prefab、图集及动态加载地址。作者源与生成物的修改方式服从项目约定。
- 同名替换 PNG 时保留 `.meta` GUID；是否修改 PPU 等字段由消费方式决定。新建资源按项目规则处理引用与 `.meta`，不要手动伪造导入缓存。
- 检查图集容量、最大尺寸及分页假设，尤其是只支持单页纹理的自定义渲染。尺寸提升后的纹理内存与面积相关，不仅与文件压缩大小相关。
- 原有透明 PNG 继续保留 alpha。纹理过滤、抗锯齿和透明边缘扩色要在实际背景上检查，不用更换检测阈值来掩盖资源不足。

## 静态缩放归一

仅在任务包含归一时处理。先区分纯美术叶节点、布局父节点和动画/脚本驱动节点；根节点、带子对象的节点及动态效果不能仅凭 scale 不为 1 就直接修改。

- 对居中、无旋转且均匀正缩放的 Simple Sprite，原局部显示宽度为 `源宽 / 原 PPU × 原 scale`。若用户要求吸收该 scale 后再按 `r` 超分，可取 `目标宽 = ceil(源宽 × 原 scale × r)`、`目标 PPU = 原 PPU × r` 并令 scale=1；高度同理。取整会产生不足一个目标像素的尺寸误差，应量化而非宣称完全相等。
- Simple 的序列化 `m_Size` 不代表当前可见尺寸。切换为 Sliced/Tiled 时用原有效显示尺寸计算 size，同时处理 PPU 和 border。非均匀缩放、负缩放、旋转或非居中 pivot 需按实际变换另算，不能套用上式。
- 同一源图被不同 scale/PPU 的消费者使用时，按显示契约生成变体；共享于其他场景的源图可隔离副本，仅改目标引用。变体保留原图来源，避免按文件名去重掉必要变体。

## 重复区域与透明空间优化

只在用户要求优化或已有格式需要保持时执行，不把高清化自动扩大成层级重构。

- Sliced 适合保持角块、拉伸平直边；Tiled 适合有真实周期的纹理。先在原图验证可重建的重复区，再压缩源图并超分；AI 与非整数重采样可能让原本完全相同的纹理变得不同，不能只凭增强图近似相等就裁掉内容。缩小的源图在推理时保留足够上下文，周期纹理可用周期扩展，导出时移除扩展区域。
- 核对 FullRect、border、PPU 和 size；需要固定周期时使用 Continuous，并验证 `核心像素 / PPU` 的世界周期。不要机械设置 Repeat 或更换材质，须按实际采样路径核对；自定义 UV/shader 效果先查消费者支持。
- 外缘透明区可裁切并补偿 pivot/偏移；内部大洞不能靠外接框裁剪消除，可拆边或角。拆块会增加 renderer 和潜在绘制开销，按实际节省面积权衡，不按固定透明百分比批量拆分。
- 拆块保留控制整组显隐/动画的容器，检查代码是否直接取得原 renderer、是否递归设置材质顺序。核对组件 owner、父子双向引用、局部坐标、sorting、材质与 alpha；将分块回拼，与拆分前图比较 alpha 及可见像素。回拼无损仍不能证明图集过滤后没有接缝。

## SVG 与 PNG

- SVG 可作为可编辑源导出 PNG；这不要求改变项目渲染管线。
- 只有用户要求直接使用 SVG 时，才检查当前 Unity 版本、已安装包及官方文档，判断 UI Toolkit、uGUI 或 SpriteRenderer 的接入方式。不把某个版本的 SVG 支持结论固定成通用前提。
- SVG 导入成 Texture2D 仍是固定像素图；矢量网格渲染的清晰度取决于曲线细分及抗锯齿。现有 `Image`、SpriteAtlas 和自定义加载器不保证能直接接受 SVG。

## 验收

静态核验资源尺寸、透明通道、引用和导入设置。按项目约定刷新导入、图集、Patch/资源包，在目标分辨率检查外观和像素报告。若不能运行 Unity，明确列出待用户执行的步骤，不宣称报告已消失。
